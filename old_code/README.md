# Old Code Archive

This folder is reserved for old, unused, or deprecated code and backup files.

### Current Active Game Files:
- `index.html` - Home screen
- `setup.html` / `setup.js` - Player configuration
- `round1.html` - `round5.html` & `round1.js` - `round5.js` - 5 gameplay rounds
- `reaction.html` / `reaction.js` - Intermediate reaction & confidence screen
- `result.html` / `result.js` - Final score & results screen
- `style.css` - Global stylesheets
- `reactions/` - GIF assets (`correct`, `wrong`, `confident-wrong`)

You can move any unused or experimental files here anytime to keep your root directory clean.
